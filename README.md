ZooManager is a desktop application developed in Java with a MySQL database to simplify zoo management.

It allows users to register and manage animals, cages, sectors, employees, and food supplies, as well as check which foods are suitable for each species. It also includes a login system and a dashboard displaying general statistics.

Objective: To centralize zoo information in a single system, improving organization, data access, and the management of daily activities.

O ZooManager é um sistema desktop desenvolvido em Java com banco de dados MySQL para facilitar o gerenciamento de um zoológico.

Ele permite cadastrar e gerenciar animais, jaulas, setores, funcionários e alimentos, além de consultar quais alimentos são indicados para cada espécie. Também possui login para controlar o acesso ao sistema e um dashboard com indicadores gerais.

Objetivo: centralizar as informações do zoológico em um único sistema, facilitando a organização, a consulta dos dados e o controle das atividades.
